# 🇱🇰 HeritageHunt - Sri Lanka's Timeless Wonders

An interactive, responsive single-page web application (SPA) built to explore, showcase, and preserve Sri Lanka's rich historical and cultural heritage.

![Project Preview](homeimg.jpg)

---

## ✨ Features

* 🗺️ **Interactive Leaflet.js Map:** Dynamic map pins covering **25 historic sites** across all 9 provinces of Sri Lanka.
* 🔍 **Real-time Search & Filter:** Instantly filter sites by **Name** or **District** via the sidebar search bar.
* 📖 **Story Modules & Modals:** Rich historical articles with modal popups for deep-dive reading.
* 📩 **Formspree Integration:** Working contact and site-suggestion form for user feedback.
* 📱 **Mobile-First & Responsive:** Smooth navigation drawer, responsive CSS grid, and touch-friendly interface.
* 🎨 **Background Slideshow:** Auto-rotating hero slideshow showcasing Sri Lankan landmarks.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Flexbox & Grid), JavaScript (ES6)
* **Mapping Library:** [Leaflet.js](https://leafletjs.com/) & OpenStreetMap
* **Icons & Fonts:** Font Awesome 6, Google Fonts (*Poppins* & *Playfair Display*)
* **Form Handling:** [Formspree](https://formspree.io/)
* **Version Control & Hosting:** Git, GitHub, GitHub Pages
